# What I Learned

Large Language Models (LLMs): Models trained on large amounts of text to learn language patterns and generate text.

1. Base LLMs: Predict the next token based on patterns learned during training.

2. Instruction-Tuned LLMs: Further trained to follow instructions and produce helpful responses.

RLHF (Reinforcement Learning from Human Feedback): A technique used to refine model behavior using human feedback.

LLM APIs: Enable developers to integrate language models into software applications.

Key Takeaway

Effective LLM applications require clear instructions, appropriate prompt design, structured outputs, and awareness of model limitations such as hallucinations.
